# Teaser

Treat `/teaser` and `$teaser` as this mode. Read [references/teaser.md](references/teaser.md) and [references/handcrafted-figures.md](references/handcrafted-figures.md), then execute the user's figure request.

Default to a dense real-result montage, short capability labels, warm paper and dark ink, with Comic Sans MS for this handcrafted profile. Keep the project title separate from the main evidence. Preserve genuine image content and expose every selected source/attempt/timestamp. Do not turn the teaser into a method flowchart or infer performance from selected examples.

Deliver editable PPTX, rendered PDF, PNG preview, caption and provenance when the available authoring runtime supports them. If asked for Overleaf delivery, preserve existing figure filenames and labels. Read the shared guide for export checks and unavailable-runtime handling. Adapt the number of frames, font and layout to the paper and explicit user preferences.
